# Commons do Hackathon — Patos de Minas 2026

Este espaço local prepara uma continuação voluntária para as ideias do Hackathon Cidades
Inteligentes. O evento termina; uma contribuição útil não precisa terminar com ele.

## Princípio

Cada equipe escolhe se quer participar e o que quer compartilhar. Autoria, histórico e
licença permanecem explícitos. Ideias diferentes continuam como projetos independentes;
ninguém incorpora trabalho alheio sem consentimento.

## O que pode entrar

- código, documentação, pesquisa, design, testes e dados públicos;
- uma ideia ainda conceitual, marcada `CONCEPT`;
- uma entrega demonstrável, marcada `REAL` e acompanhada de evidência;
- um problema financiável, com contratante, valor e aceite declarados antes do trabalho.

## O que não entra

- CPF, placa, rosto identificável ou outro dado pessoal sem base e autorização;
- dado policial, sigiloso ou recebido para finalidade incompatível;
- promessa de remuneração sem contratante, valor e critério de aceite;
- afirmação de que algo funciona sem teste ou demonstração reproduzível.

## Como participar

1. Abra o formulário “Quero continuar minha ideia” ou “Novo projeto”.
2. Declare autores, problema, estágio, evidências e licença pretendida.
3. Use uma issue para cada entrega verificável.
4. Envie mudanças por pull request; autoria e revisão ficam no histórico.

Leia [CONTRIBUTING.md](CONTRIBUTING.md) e [POLITICA.md](POLITICA.md). Este material ainda
não é um repositório publicado e não escolhe a licença definitiva.
