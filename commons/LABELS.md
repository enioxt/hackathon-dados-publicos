# Labels iniciais

| Label | Uso |
|---|---|
| `stage:concept` | ideia ainda não demonstrada |
| `stage:prototype` | demonstração parcial |
| `stage:real` | comportamento provado |
| `help-wanted` | contribuição aberta |
| `research` | investigação com fontes |
| `data-public` | dado público com proveniência |
| `privacy-review` | exige revisão de privacidade |
| `bounty-proposed` | remuneração proposta, ainda sem contrato completo |
| `bounty-ready` | contratante, valor e aceite preenchidos |
| `blocked:human-decision` | depende de decisão humana |
