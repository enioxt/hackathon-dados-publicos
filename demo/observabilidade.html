O que é real e o que é simulado

    2. 
      
  2. Sem câmera conectada — como agora, se você está vendo o aviso amarelo no topo — o sistema mostra os mesmos passos com números inventados, sempre marcados como simulado.
    3. 
      
  3. Mostramos os dois porque a banca precisa ver o fluxo inteiro funcionando, mesmo sem uma câmera real na hora da apresentação.
    4. 
      
  4. A contagem em si (quantos carros passaram) e a comparação com a média não usam nenhuma IA de texto — é conta, não redação.
    5. 
      
  5. Só o assistente de perguntas usa um modelo de linguagem, e só para explicar o número em português — nunca para decidir se um dado entra no sistema.
