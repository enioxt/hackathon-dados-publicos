Do que é feito

Quatro camadas, cada peça escolhida por um motivo específico.

Leitura de vídeo

  • Python
  • YOLO11n (detecção)modelo pequeno: roda em CPU comum
  • ByteTrack (rastreio)
  • OpenCV

Porta de entrada e dados

  • Bun + TypeScript
  • SQLite
  • Validação de esquema
  • Verificador de dado pessoalrecusa o que tiver placa ou nome

Decisão

  • Regras determinísticas para númeronúmero decide por regra, não por modelo
  • Classificador de texto (Jev)só para relato livre
  • Baixa confiança vai para pessoa

Tela e publicação

  • HTML/CSS/JS sem framework
  • SVG
  • GitHub Pages · Actions
  • Túnel temporárioabre em qualquer navegador, sem instalar
Análise do que já foi gravado — com atraso, de propósito
Contar trânsito e medir antes e depois não exige ver a rua no instante; exige ver a mesma hora de muitos dias. Sem transmissão contínua não há sala de monitoramento, não há rede dedicada e o risco de privacidade cai: só trafega número.
Construído com assistentes de IA (Claude Fable 5.1, Sonnet 5, Opus 5) sob revisão humana; transcrição de áudio por Whisper large-v3.
